# Europe_Sales_Dashboard


## 📌 Overview  
This project presents a detailed **Europe Sales Analysis Dashboard** designed to deliver insights into sales performance across multiple European countries. The dashboard provides a comprehensive view of **revenue, sales channels, product categories, and order priorities**, empowering decision-makers to identify trends, optimize operations, and maximize profitability.

## 🎯 Key Performance Indicators (KPIs)  
The dashboard tracks the following business-critical KPIs:  

- 💰 **Total Revenue** – Profitability across European countries  
- 📦 **Units Sold** – Quantity of products sold by item type  
- 🌍 **Top Profitable Countries** – Highest revenue-generating regions  
- 🛒 **Sales Channels** – Online vs. Offline contribution  
- 🏷️ **Item Type Analysis** – Category-wise sales distribution (Office Supplies, Beverages, Fruits, Clothes, Vegetables, Baby Food)  
- 📑 **Order Priority Performance** – Contribution of High, Medium, Low, and Critical orders  
- 📈 **Country-Wise Sales Trends** – Comparison across European regions
